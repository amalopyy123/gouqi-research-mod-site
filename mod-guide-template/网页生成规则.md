# Mod 介绍网页生成规则

这份文件记录“根据文案和图片生成 Mod 介绍网页”的固定规则。以后重新生成或更新页面时，应优先遵守这些规则。

## 一、文案来源

1. 只使用用户明确指定的文案文件。
2. 如果用户说明某些 TXT 已经过时，必须忽略这些旧文件。
3. 生成前先完整读取指定文案，确认标题、编号、段落和图片标记。
4. 尽量逐字保留原文，不擅自概括、润色、翻译或省略内容。
5. 文案中使用的标点、大小写、空格、中文名称和日文名称应尽量保持原样。
6. 保留原文编号，例如：
   - `1.`、`2.`、`10.`、`10.5`
   - `1.1 版本的更新1`
   - `更新7.1`、`更新7.2`

## 二、文字与图片顺序

1. 图片必须按照文案中出现的位置插入。
2. 文字和图片按原文顺序穿插，例如：

   ```text
   第一段文字
   图片1
   第二段文字
   图片2
   第三段文字
   ```

3. 不要把一个功能的所有文字先显示，再把所有图片统一放在末尾。
4. 如果一项更新包含多段文字和多张图片，应分别按照原文顺序排列。
5. 如果 7.1 和 7.2 是两个独立编号，必须生成两个独立功能卡片，不能合并。

## 三、页面布局和样式

1. 使用单列布局，所有内容从上到下显示。
2. 不使用左右两栏来并排展示功能介绍。
3. 图片尽量显示得大一些，避免缩成过小的缩略图。
4. 图片可以点击放大查看。
5. 页面应支持桌面和手机屏幕。
6. 延续现有页面的颜色、字体、卡片和间距风格。
7. 页面中的代码注释必须使用英文。

## 四、图片处理

1. 只复制文案实际引用的图片，不要把素材目录中所有图片全部复制进去。
2. 图片按版本分类保存：

   ```text
   images/v1.0/
   images/v1.1/
   images/v1.2/
   ```

3. 新版本可以新建对应目录，例如 `images/v1.3/`。
4. 图片文件名必须与实际文件名完全一致，包括：
   - 中文字符
   - 扩展名
   - 大小写
   - 数字后缀
5. 文案中出现的每一张图片都必须检查是否存在。
6. 如果图片缺失、重名、扩展名不一致或无法判断版本，记录到 `ISSUES.md`，不要默默替换成其他图片。
7. 图片使用相对路径，不能使用本机绝对路径。

## 五、输出页面

每次生成时，通常需要同步两个版本：

### Cloudflare Pages 版

放在：

```text
git文件/gouqi-research-mod-site/mod-guide/
```

常用文件包括：

- `index.html`
- `styles.css`
- `layout-overrides.css`
- `guide.js`
- `original-text.js` 或其他内容脚本
- `content-flow.js` 或其他顺序脚本
- `images/`

### Mod 离线版

放在用户指定的 Mod 文件夹中，例如：

```text
修改器发帖/mod/mod功能介绍（请提前看）/
```

离线版 HTML 必须可以直接双击打开，不依赖本地服务器。线上版和离线版的文字、图片、顺序和样式应保持同步。

## 六、下载链接和隐私内容

默认情况下，Mod 介绍页不要包含：

- 百度云链接
- GitHub 链接
- 提取码
- 解压密码
- 下载按钮
- 其他容易失效或被和谐的外部链接

只有用户明确要求时，才在指定页面添加这些内容。数据库首页的下载配置与 Mod 介绍页分开处理。

## 七、生成前检查

生成前应检查：

- 指定的文案文件是否存在。
- 文案编码是否正确，中文是否乱码。
- 文案中的编号是否完整。
- 文案中的图片引用数量。
- 每张引用图片是否存在。
- 是否误用了旧版 TXT。
- 是否有新增、删除或重命名的图片。
- 线上版和离线版的目标目录是否明确。

## 八、生成后检查

生成后应检查：

- 文字是否按照原文显示。
- 编号是否保留。
- 文字和图片顺序是否一致。
- 7.1、7.2 等独立项目是否被错误合并。
- 图片是否过小。
- 图片点击放大是否正常。
- 所有图片路径是否有效。
- 线上版和离线版是否同步。
- 页面是否意外包含下载链接或密码。
- JavaScript 文件是否通过语法检查。

## 九、问题记录

发现任何问题都记录到页面目录中的 `ISSUES.md`，包括：

- 文案编码转换。
- 缺失图片。
- 图片名称或扩展名不一致。
- 旧文件与新文件内容冲突。
- 线上目录或离线目录不存在。
- 页面引用路径错误。
- 用户文案中存在无法确定的图片归属。
- 生成过程中出现的复制或同步错误。

问题修复后不要删除原始记录，应补充说明解决方式。

```text
只使用我指定的文案文件，忽略旧文案；尽量逐字保留原文，不要概括或省略；保留全部编号；图片必须按照文案出现顺序穿插；使用单列布局和较大的图片，并支持点击放大。

请只复制文案实际引用的图片，按版本放入 images/vX.Y/；同时生成 Cloudflare Pages 版和 Mod 文件夹内可双击打开的离线版；线上版和离线版保持同步。

默认不要在 Mod 介绍页加入百度云、GitHub、提取码、解压密码或下载链接。

生成前后检查文案编码、图片路径、编号、顺序和缺失文件；遇到问题记录到 ISSUES.md。代码注释使用英文。
```
